# Security Policy

## Reporting False Positives

If a legitimate domain is incorrectly included in our blocklists, please open an issue using the **False Positive Report** template.

## Reporting Malicious Submissions

If you suspect someone has submitted domains with the intent to block legitimate services (e.g., competitors, political targets), please email: esteban.esquivel@mava.com.co

## Data Sources

All domains are aggregated from reputable open sources. We do not accept anonymous bulk submissions without verification.
