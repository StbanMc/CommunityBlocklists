# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free experience for everyone. This project exists to improve internet safety, not to enable censorship.

## Standards

**Acceptable:**
- Adding verified malicious, adult, gambling, or other categorized domains
- Reporting false positives
- Suggesting improvements to scripts or formats
- Constructive feedback

**Unacceptable:**
- Submitting domains to block competitors or for personal vendettas
- Using the project for political censorship
- Harassment of contributors
- Submitting domains without proper categorization

## Enforcement

Project maintainers may remove contributions and ban contributors who violate this code of conduct.
